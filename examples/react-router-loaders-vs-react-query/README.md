# React Router loaders vs TanStack Query

One deterministic API and Zod schema, presented through two orchestration styles. Both scenarios use React Hook Form so the comparison includes third-party form integration rather than only idealized native forms.

```bash
corepack pnpm --filter @kahwee-labs/react-router-loaders-vs-react-query dev
```

This browser example studies API expressiveness. It does not claim SSR or performance results; those belong in the separate benchmark package.
